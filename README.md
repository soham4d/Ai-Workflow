# AI Workflow Stack

A personal system mapping AI models to specific tasks based on their strengths.

## Models & Tasks

- **Gemini** — Test paper generation across subjects (Physics, Chemistry, Maths)
- **ChatGPT** — General purpose tasks and brainstorming
- **Claude** — Building small HTML trackers and structured code
- **Perplexity Sonar** — Real-time research on MEXT requirements and global news

## Why This Structure

Each model was chosen based on observed comparative advantage. Gemini excels at structured document generation. ChatGPT is reliable across domains. Claude is strong at code. Perplexity retrieves current information.
